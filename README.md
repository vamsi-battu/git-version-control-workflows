# Git Practice Repository

# Overview
This repository contains practical examples and hands-on usage of Git commands used in real-world development workflows.

The purpose of this project is to strengthen understanding of version control concepts and simulate real-time development scenarios using Git.

---

# Objectives

- Understand core Git concepts
- Practice daily Git commands used in projects
- Learn branching, merging, and conflict resolution
- Simulate real-world development workflows

---

# Tools Used

- Git (Version Control System)
- GitHub (Code Hosting Platform)

---

# Topics Covered

# Basic Commands
- git init
- git clone
- git add
- git commit
- git status

### 🔹 Branching & Merging
- git branch
- git checkout
- git merge

# Remote Repository
- git push
- git pull
- git fetch

# Advanced Concepts
- Handling merge conflicts
- Undo changes (reset, revert)
- Working with branches in collaborative environments

---

# Workflow Practiced

1. Initialize repository
2. Create and modify files
3. Stage changes using `git add`
4. Commit changes with meaningful messages
5. Push code to remote repository
6. Create branches for new features
7. Merge branches into main branch

---

# Key Learnings

- Git helps in tracking code changes efficiently :contentReference[oaicite:1]{index=1}  
- Branching enables parallel development without affecting main code  
- Version control improves collaboration and reduces risk  
- Commit history acts as a source of truth for project changes

# Real-World Use Case

In real projects:
- Developers work on separate branches
- Code is reviewed before merging
- Git ensures version tracking and rollback capability
- Teams collaborate without overwriting each other's work
